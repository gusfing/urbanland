### **Page Speed & Core Web Vitals Checklist**

* All images converted to WebP format

* Hero image lazy-load disabled (above fold) — all other images lazy-loaded

* LCP (Largest Contentful Paint) target: under 2.5 seconds

* CLS (Cumulative Layout Shift): no layout shifts from late-loading fonts or images

* Use system fonts or preload custom fonts to avoid FOUT

* Minify CSS, JS, and HTML

* Enable Gzip/Brotli compression on server

* Add proper canonical tags on every page

* Submit XML sitemap to Google Search Console after launch
